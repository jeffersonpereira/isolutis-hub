================================================================================
                      COMO USAR AGORA
================================================================================

1. INSTALAR DEPENDÊNCIAS
   cd frontend && npm install
   cd backend && pip install -e ".[dev]"

2. RODAR TESTES
   npm test (frontend)
   pytest (backend)

3. APLICAR HELPER EM NOVO FORMULÁRIO
   Ver exemplo completo em: IMPLEMENTACAO.md (Seção "Como Usar")

   Padrão simples:
   import { salvarComValidacao } from "@/ui/salvar-helper";

   await salvarComValidacao({
     form: f,
     botaoSalvar: botao,
     validar: () => { /* sua lógica */ },
     operacao: () => tentar(() => api.fazer(...)),
     recarregarRecurso: "seu-recurso",
     fechar,
   });

4. MELHORAR ACESSIBILIDADE DE FORMULÁRIO
   import { melhorarFormulario } from "@/ui/acessibilidade";
   melhorarFormulario(formElement);

5. AUDITAR SEGURANÇA
   Ver: docs/RLS_AUDIT.md (checklist completo)
